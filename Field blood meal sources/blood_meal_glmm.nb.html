host_blood analysis

This notebook assess mosquito blood meal sources

Data description

An experiment was conducted in Tulizamoyo to to assess the proportion of two Anopheles mosquito Species: An. funestus and An. arabiensis (species), blood feeding on vertebrates (host_blood). The experiment was done in a field setting, and mosquitoes were collected in different houses (hh_id), using different traps (trap_method), indoors and outdoors (position). PCR targeting cytocrome b was performed on the samples collected, and the number of amplified samples were recorded (count).

Key question: What type of host do anopheles mosquitoes prefer to feed on, when the host availability is almost 50/50?

Model Fitting

House hold Id will be treated as the random effects because we aren’t interested in generalizing their effects beyond the experiment.

Host, mosquito species, position, and trap method are treated as fixed/explanatory variables because the purpose of the experiment is to generalize the HOST preference on the number of mosquitoes blood fed on different vertebrates .

The response variable count (no. of mosquitoes blood fed on a particular host), is modeled against the explanatory variables:

  1. Host (different vertebrate which mosquito blooed-fed) - a factor with six levels

  2. Position (indoor/outdoor collection) - a factor with two levels

  3. Species (An. funestus/An. arabiensis) - a factor with two levels

and INDIVIDUALS (different individuals used in the study) as a random effect

Null hypothesis

N0: Anopheles mosquitoes prefer to bite humans than other vertebrate.

Since our response variable is a count, then Poisson GLMM will be a suitable model structure.

We will to fit a number of different models from complicated to simple, and likelihood ration test to test the importance of each variable in the model

# Checking for over dispersion 

overdisp_fun <- function(model) {
  rdf <- df.residual(model)
  rp <- residuals(model,type="pearson")
  Pearson.chisq <- sum(rp^2)
  prat <- Pearson.chisq/rdf
  pval <- pchisq(Pearson.chisq, df = rdf, lower.tail = FALSE)
  c(chisq = Pearson.chisq, ratio = prat, rdf = rdf, p = pval)
}
