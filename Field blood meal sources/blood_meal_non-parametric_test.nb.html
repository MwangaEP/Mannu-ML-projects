host_blood analysis

This notebook assess mosquito blood meal sources

Data description

An experiment was conducted in Tulizamoyo to to assess the proportion of two Anopheles mosquito Species: An. funestus and An. arabiensis (species), blood feeding on vertebrates (host_blood). The experiment was done in a field setting, and mosquitoes were collected in different houses (hh_id), using different traps (trap_method), indoors and outdoors (position). PCR targeting cytocrome b was performed on the samples collected, and the number of amplified samples were recorded (count).

Key question: What type of host do anopheles mosquitoes prefer to feed on, when the host availability is almost 50/50?

The hypotheses of the Fisher’s exact test are the same than for the Chi-square test, that is:

H0 : the variables are independent, there is no relationship between the two categorical variables. Knowing the value of one variable does not help to predict the value of the other variable

H1 : the variables are dependent, there is a relationship between the two categorical variables. Knowing the value of one variable helps to predict the value of the other variable

The contingency table above confirms that we should use the Chi-square test because there there is no at least one cell below 5.

The Chi-square test of independence tests whether there is a relationship between two categorical variables. The null and alternative hypotheses are:

H0: the variables are independent, there is no relationship between the two categorical variables. Knowing the value of one variable does not help to predict the value of the other variable

H1: the variables are dependent, there is a relationship between the two categorical variables. Knowing the value of one variable helps to predict the value of the other variable

The Chi-square test of independence works by comparing the observed frequencies (so the frequencies observed in your sample) to the expected frequencies if there was no relationship between the two categorical variables (so the expected frequencies if the null hypothesis was true).
